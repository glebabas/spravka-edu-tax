> **Генератор справок об оплате образовательных услуг по форме КНД 1151158**

## 📌 О проекте

Приложение предназначено для образовательных организаций, онлайн-школ, курсов, учебных центров и индивидуальных предпринимателей (ИП), осуществляющих образовательную деятельность.

Оно автоматизирует создание официальных справок об оплате образовательных услуг для представления в налоговые органы (ФНС России) с целью получения налогоплательщиками социального налогового вычета.

Документ формируется с **миллиметровой точностью** по сетке клеток ФНС (стандарт 5.0 мм) на базе официального двухстраничного бланка, поддерживает вставку факсимиле подписи, умную компрессию PDF-потоков (размер готового файла всего ~200 КБ вместо 1.6 МБ) и пакетную обработку сотен справок из Excel/CSV.

## 📋 Статические и динамические поля

В соответствии с требованиями и структурой формы КНД 1151158 все поля разделены на две группы:

### 1. Статические поля (Реквизиты организации / ИП)
*Задаются один раз в `config.json` или через веб-интерфейс и автоматически проставляются во все справки:*

| Поле формы | Описание | Значение в профиле по умолчанию |
|---|---|---|
| **ИНН организации / ИП** | 12 клеток для ИП или 10 клеток для юрлица (в шапке стр. 1 и стр. 2) | `773610841807` |
| **КПП** | 9 клеток (заполняется только организациями, для ИП остается пустым) | *(пусто)* |
| **Данные образовательной организации / ИП** | Наименование организации или ФИО ИП (4 строки клеток по 40 символов) | `ИНДИВИДУАЛЬНЫЙ ПРЕДПРИНИМАТЕЛЬ`<br>`БУРЛАКОВ НИКИТА СЕРГЕЕВИЧ` |
| **Обучение проводилось по очной форме** | Признак формы обучения: `0` — нет (онлайн, заочно, курсы), `1` — да (очная форма) | `0` *(нет)* |
| **Достоверность сведений подтверждаю** | ФИО ответственного лица / руководителя / ИП (3 строки клеток) | Фамилия: `БУРЛАКОВ`<br>Имя: `НИКИТА`<br>Отчество: `СЕРГЕЕВИЧ` |
| **Факсимиле подписи** | Графическое изображение подписи на прозрачном фоне (ставится на стр. 1 и 2) | `assets/signature.png` |
| **Код вида документа** | По умолчанию код паспорта гражданина РФ | `21` |
| **Количество страниц** | Справка составлена на страницах | `002` |

> 💡 **Для публикации на GitHub**: в репозитории подготовлен файл `config.example.json` с пустыми значениями, а в веб-интерфейсе встроен переключатель профилей: *«ИП Бурлаков Н. С.»* и *«Чистый шаблон (для GitHub)»*.

---

### 2. Динамические поля (Данные конкретного ученика/клиента)
*Уникальны для каждого выдаваемого документа:*

| Поле формы | Формат / Пример | Примечание |
|---|---|---|
| **Номер справки** | `031`, `032`, `035`... | Поддерживается авто-инкремент (`+1`) |
| **Номер корректировки** | `0` (первичная), `1`, `2`... | Обычно `0` |
| **Отчетный год** | `2025`, `2026` | Год, в котором фактически произведена оплата |
| **Дата составления** | `01.07.2026` | Формат ДД.ММ.ГГГГ |
| **ФИО налогоплательщика** | `СИМОНОВА НИНА АНАТОЛЬЕВНА` | Автоматический перевод в ВЕРХНИЙ РЕГИСТР |
| **Дата рождения** | `03.07.1958` | С умным позиционированием вокруг разделительных точек |
| **ИНН плательщика** | 12 цифр | Необязательно (при наличии) |
| **Серия и номер паспорта** | `4506 765502` | Маска ввода `ХХХХ ХХХХХХ` |
| **Дата выдачи паспорта** | `13.01.2004` | Формат ДД.ММ.ГГГГ |
| **Сумма расходов** | `139 758.00` | Рубли выравниваются по правому краю к точке, копейки — 2 знака |
| **Признак одного лица** | `1` — да, `0` — нет | Если `0`, на странице 2 указываются отдельные данные обучаемого (ребенка/супруга) |
| **Данные обучаемого (стр. 2)** | ФИО, дата рождения, паспорт | Заполняются, если оплату вносил родитель/супруг за другого человека |

## ✨ Ключевые возможности приложения

- 🎯 **Идеальная точность сетки:** Символы центрируются в каждой клетке с шагом 14.173 pt (5 мм) согласно стандарту налоговых бланков.
- ⚡ **Два режима работы:**
  - 🌐 **Интерактивный веб-интерфейс (GUI)**: локальный сервер с живым предпросмотром PDF, печатью в 1 клик и скачиванием.
  - 💻 **Консольный режим (CLI)**: для скриптов, терминала и CI/CD.
- 📊 **Пакетная генерация из Excel и CSV:** Загружаете таблицу с десятками или сотнями учеников — получаете готовые справки в папке `output/` за пару секунд!
- ✍️ **Интерактивный Signature Pad:** Возможность использовать сохраненное факсимиле, загрузить файл подписи или нарисовать новую подпись прямо на экране мышкой или стилусом.
- 🗜️ **Оптимизация размера PDF:** Готовые файлы весят всего ~200 КБ благодаря сжатию потоков FlateDecode (вместо 1.6 МБ при стандартном экспорте).
- 🔒 **Конфиденциальность:** В репозитории настроен `.gitignore`, защищающий от случайной публикации персональных данных клиентов в публичный репозиторий.
- 🌐 **Автономность:** Веб-интерфейс может работать даже без Python, прямо в браузере через `pdf-lib` при открытии `web/index.html`.

## 🚀 Быстрый старт

### Вариант 1. Запуск в 1 клик на Windows
Просто дважды кликните по файлу **`run.bat`** в папке проекта. Скрипт проверит окружение, установит зависимости и откроет приложение в вашем браузере.

### Вариант 2. Ручной запуск через Python

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/spravka-edu-tax.git
   cd spravka-edu-tax
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите веб-приложение:**
   ```bash
   python app.py
   ```
   *Приложение автоматически откроется по адресу `http://localhost:8080`.*

## 💻 Использование через командную строку (CLI)

### Одиночная генерация справки:
```bash
python cli.py --number 035 --last-name "ИВАНОВ" --first-name "ИВАН" --middle-name "ИВАНОВИЧ" \
  --birth-date "15.05.1985" --passport "4508 123456" --doc-issue-date "20.06.2005" \
  --amount 120000 --year 2025 --date "01.07.2026"
```

Или с передачей ФИО одной строкой:
```bash
python cli.py --number 035 --fio "Иванов Иван Иванович" --birth-date "15.05.1985" \
  --passport "4508 123456" --doc-issue-date "20.06.2005" --amount 120000
```

### Пакетная генерация из Excel или CSV таблицы:
```bash
# Из таблицы Excel (.xlsx):
python cli.py --batch template_clients.xlsx --out output

# Из файла CSV (.csv):
python cli.py --batch template_clients.csv --out output
```
*Все сгенерированные файлы будут сохранены в папку `output/` с именами вида `035 ИВАНОВ справка.pdf`.*

## 📊 Формат таблицы для пакетной генерации

Приложение поддерживает гибкие названия колонок на русском и английском языках (Excel `.xlsx` или `.csv`):

| Колонка в таблице | Пример | Описание |
|---|---|---|
| `Номер справки` / `number` | `035` | Номер документа (если не указан, нумеруется автоматически) |
| `Год` / `year` | `2025` | Отчетный год |
| `Дата справки` / `doc_date` | `01.07.2026` | Дата составления справки |
| `Фамилия` / `last_name` | `ИВАНОВ` | Фамилия плательщика |
| `Имя` / `first_name` | `ИВАН` | Имя плательщика |
| `Отчество` / `middle_name` | `ИВАНОВИЧ` | Отчество плательщика |
| `Дата рождения` / `birth_date` | `15.05.1985` | Дата рождения (ДД.ММ.ГГГГ) |
| `Паспорт` / `passport` | `4508 123456` | Серия и номер паспорта |
| `Дата выдачи` / `issue_date` | `20.06.2005` | Дата выдачи паспорта |
| `Сумма (руб.)` / `amount` | `120000.00` | Сумма расходов на обучение |
| `Корректировка` / `correction`| `0` | Номер корректировки (0 по умолчанию) |

Готовые образцы файлов находятся в корне проекта:
- `template_clients.xlsx`
- `template_clients.csv`

## 💡 Предложения и идеи по развитию проекта

1. **Генерация QR-кода платежных/налоговых данных:**
   В бланке справки справа внизу предусмотрена официальная «Зона QR-кода». В будущей версии можно формировать двухмерный QR-код (по ГОСТ Р 56042-2014) с реквизитами справки, чтобы инспектор ФНС мог моментально сканировать документ.
2. **Автоматическая отправка на Email / Telegram:**
   Добавить кнопку «Отправить справку клиенту», которая формирует письмо с прикрепленным PDF и отправляет его на указанный email ученика или через Telegram-бота школы.
3. **Реестр выданных справок:**
   Ведение локальной базы данных (SQLite) с историей всех выданных справок, возможностью быстрого поиска по фамилии, повторной печати или формирования сводного отчета для бухгалтерии за год.
4. **Интеграция с CRM / GetCourse / 1C:**
   Возможность выгружать данные об оплатах напрямую через API вашей CRM или GetCourse для автоматической генерации справок без ручного заполнения Excel.
5. **Двусторонний режим для обучаемого (ребенка):**
   Приложение уже полностью поддерживает сценарий, когда плательщик и обучаемый — разные лица (родитель оплатил обучение ребенка), с отдельным заполнением реквизитов ребенка на странице 2.

## 🧪 Тестирование

Для запуска автоматических тестов выполните:
```bash
python -m unittest discover tests
```
Все тесты проверяют корректность генерации одностраничных и двухстраничных документов, парсинг сумм, вставку подписи и целостность PDF.
